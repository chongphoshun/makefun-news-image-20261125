A one-page newspaper front page that sums up Wednesday, 25 November 2026 in
a single 1024×1024 image: 50 verified stories across 7 regions — China
flies the first Pakistani astronaut aboard Tiangong, the Solomon Islands
signs an A$740m security treaty with Australia, and Asian stocks dive on a
US tariff threat. Every story happened or was first reported on 25 November
2026; items first reported that day are marked REPORTED, unverified claims
are marked CLAIMED. A "By the Numbers" strip, a per-region count strip, and
35 one-line briefs complete the page.

The image is generated by `draw.py` (Pillow + DejaVu fonts, run at build
time only — regenerate with `python3 draw.py`). The submitted program,
`main.py`, is standard-library only: it copies the pre-rendered `entry.png`
to the output directory, verifies the PNG header is 1024×1024, and checks
the copy's sha256 matches the source.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` and prints its byte count and sha256. Without
`MAKEFUN_OUTPUT_DIR` set, the image goes to `/output/entry.png`.
